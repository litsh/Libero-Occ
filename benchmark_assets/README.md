# Benchmark Assets

This directory contains the released LIBERO-Occ benchmark assets.

```text
bddl_files/libero_spatial_occluded
bddl_files/libero_goal_occluded
bddl_files/libero_object_occluded
bddl_files/libero_10_occluded
init_files/libero_spatial_occluded
init_files/libero_goal_occluded
init_files/libero_object_occluded
init_files/libero_10_occluded
```

Install these assets into an upstream LIBERO checkout with:

```bash
export LIBERO_ROOT=/path/to/LIBERO
bash scripts/setup/install_libero_occ_assets.sh
```

The benchmark-generation pipeline is not part of this release.
